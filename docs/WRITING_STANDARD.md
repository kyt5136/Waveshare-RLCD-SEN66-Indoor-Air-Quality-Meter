# Documentation Writing Standard

This project uses an ASD-STE100 flavored style for general technical prose.

The project does not claim formal ASD-STE100 certification.

Use these rules for README files, operation guides, release notes, and pull request text:

- Use one name for one thing.
- Use active voice when the actor is known.
- Use short sentences.
- Put one topic in each paragraph.
- Use a verb for each action.
- Use American spelling.
- Do not use contractions.
- Do not use semicolons.
- Do not use marketing adjectives.
- Put a condition before its instruction.

Use numbered steps for procedures. Write one command in each step.

See the [official ASD-STE100 site](https://asd-ste100.org) for standard information.
